# Gyro Research Notes

Brainstorming, pre-theoretical studies, and multi-AI review records for the Gyro Project.

This repository is used to preserve exploratory research notes before they are promoted into formal Gyro Logic / GyroOS / GyroAuth artifacts.

## Purpose

- Preserve exploratory ideas without prematurely turning them into formal definitions.
- Keep the history of conceptual development visible.
- Review important checkpoints with multiple AI systems.
- Record critiques separately from the source idea document.
- Use critique cycles to refine ideas before any formal Gyro-layer integration.

## Repository structure

```text
.
├─ ideas/
│  └─ information/
├─ prompts/
│  └─ review_common.md
└─ docs/
   └─ workflow.md
```

## Current research area

The first research stream under `ideas/information/` concerns the pre-theoretical investigation of information, PULL, local establishment, continuous flow (`~ing`), locally usable establishment (`~ed`), and retroactive access / retrospective PULL.

These terms are provisional. They must not be treated as established Gyro Logic definitions unless a later review explicitly promotes them.

## Review policy

Important idea checkpoints should be reviewed by multiple AI systems such as ChatGPT, Claude, and Gemini.

The common review prompt is stored in:

- `prompts/review_common.md`

Reviews should focus on contradictions, ambiguous definitions, overlap with prior theories, counterexamples, falsifiability, over-generalization, and the next useful test cases.

## Relationship to the Gyro Project

This repository is a research notebook and review workspace. It is intentionally separated from the formal Gyro repositories.

Ideas here may later inform Gyro Logic, GyroOS, GyroAuth, or other Gyro Project artifacts, but no such mapping should be assumed in advance.
